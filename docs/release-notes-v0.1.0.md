## MediaShelf v0.1.0

影视库整理工具的首个可执行版本。下载 `MediaShelf.exe` 双击即可运行，不需要安装 Python。

### 下载

| 文件 | 说明 |
|---|---|
| `MediaShelf.exe` | Windows 10/11 64 位单文件版，约 46 MB |

**还需要 ffmpeg**：程序靠 `ffprobe` 读取分辨率、编码、HDR、音轨等信息。没有的话先装：

```powershell
winget install Gyan.FFmpeg
```

程序会自动在 PATH 和常见目录里找 `ffprobe.exe`，找不到时在「设置」里手动指定路径。

### 三个功能

- **重命名**：模板化命名，字段包括中英文名、年份、分辨率、片源、编码、HDR、音轨、发布组，实时预览结果。内置四套预设，也可以自己拼。
- **整理文件夹**：按 `片名 (年份)` 归档，系列电影自动归入 `XXX Collection`，同名字幕跟随视频改名。
- **nfo**：生成 Kodi 标准 `movie.nfo`，可同步下载 poster / fanart；删除前默认备份到 `_nfo_backup`。

### 数据源

优先 TMDB（需要免费 Key，在「设置」里填），没有 Key 时降级到维基百科，只能拿到中英文名、年份和简介。

### 安全边界

- 全部操作用 `os.rename`，同盘改名不搬运数据；跨设备直接报错，不会偷偷复制把磁盘写满
- 执行前弹出完整操作清单，逐条列出源路径与目标路径
- 每次执行写 CSV 日志，可以一键撤销
- 目标文件已存在时跳过，绝不覆盖

### 首次启动说明

单文件版会先把自身解压到临时目录，第一次启动会卡 3～8 秒，属于正常现象。以后启动会快一些。

如果程序崩溃，详细信息会写到 `%APPDATA%\MediaShelf\crash.log`，同时弹窗提示。

### 已知限制

- 片源（BluRay / WEB-DL / REMUX）无法从码流直接判断，原文件名里没有时会按码率和体积推断，可能不准，可在表格里改
- 只处理电影，剧集需要按 `SxxExx` 编排，不在当前范围
- ISO 与 BDMV 目录只识别外层文件，不会进入 `STREAM` 目录逐段处理
- 维基百科匹配对中文片名的准确率明显低于 TMDB
