# MediaShelf v0.3.0

新增综艺整理模式。实测 N:\综艺 40 个文件全部自动归位（正片 28 + 特别篇 12），0 人工。

## 综艺支持

综艺的集号是「期」，一期拆上下两集。TMDB 对国产综艺的组织方式正好配合：上/下是独立集（第1期上=E01、第1期下=E02），每集带播出日期。

**三级集号定位**（文件名 `2026-07-25 第5期上.mkv`）：

1. 播出日期精确匹配 TMDB air_date——零歧义，主力
2. 「第N期上/下」在季内集标题里唯一命中
3. 期号数学映射（上=N*2-1、下=N*2）验证该集存在

目录里的季号（`S02/`）优先锁定候选季，避免跨季「第6期上」歧义。

**非正片归 Specials（Season 00）**：加更、花絮、抢先看、先行、会员内容、先导篇（无期数的「XX篇」）在 TMDB 没有集条目。硬编进正片集号会和 TMDB 集序错位，统一归入 Season 00 按播出日期编 S00E01..n，文件名保留原标题。Jellyfin/Emby 显示为特别篇。

单集 nfo 对 Specials 不写 TMDB uniqueid（剧级 id 写进单集会让刮削器错链到正片）。
