## MediaShelf v0.1.4

这一版修两个界面问题，补一个执行后的收尾环节。

### 修：网络错误把窗口撑变形

没开代理时 `requests` 的报错有几百字符（带完整 URL、端口、超时参数），原来直接塞进数据源标签和日志区，标签的宽度直接把整个窗口顶到屏幕外。

- 错误信息统一压成一句话：「连接超时，检查网络或代理」「Key 无效（401）」「被限流（429）」
- 状态标签不再参与最小宽度计算，超出裁掉、全文放 tooltip
- 日志区关掉自动换行和横向滚动条，写入时按 96 字符硬折行

实测：输入 300 字符的完整报错，窗口最小宽度 748px，不再被撑开。

### 修：同一系列分裂成两个合集目录

TMDB 对同一个系列会返回不同的合集名——`海扁王（系列）` 和 `海扁王 Collection`，直接拼路径就得到两个文件夹，一个装满片、一个空着。

- 合集名先归一：去掉 `（系列）` `(系列)` `Collection` `合集` 等后缀
- 再按 TMDB 的 `collection_id` 复用目录名，id 缺失时退回归一化片名
- 同一个系列无论 TMDB 怎么改名，只会有一个目录

### 新增：移走后原目录的残留文件

一部片搬走，原目录里往往还留着 `poster.jpg`、旧的 `movie.nfo`、`sample.mkv`、额外的音轨 `mka` 或外挂字幕。以前这些就留在原地，既占空间也让刮削器认错。

现在执行完会弹一个对话框，列出每个空壳目录和里面的文件（名称 + 大小），三个选择：

- **一起移到新目录**：海报、字幕、音轨跟着片走
- **删除这些文件**：二次确认，明确提示网络盘删除不进回收站
- **保留不动**：什么都不做

默认全选、默认动作是保留，不会自作主张删东西。

### 判定规则

- 只统计「视频已搬走、目录还在、目录里还有文件」的情况
- 片子平铺在库根目录时不算残留
- 同一目录里有两部片时，等所有移动做完再统计，不会把还没搬的那部误判成残留
