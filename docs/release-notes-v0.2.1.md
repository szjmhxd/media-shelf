# MediaShelf v0.2.1

## 译名对不上也能匹配上了

自动匹配此前只拿一个中文查询词去搜 TMDB。遇到「本地叫法」和「TMDB 官方译名」不一致的片子，正确答案根本不在搜索结果里，反而会被字面相近的同名片顶掉。两个典型案例：

| 文件 | 旧行为 | 新行为 |
|---|---|---|
| `长发公主.Tangled.2010…` | 错配《芭比之长发公主》(2002)，需人工确认 | 命中《魔发奇缘》(2010) |
| `碧蓝之海真人版…` | 无匹配，目录名变成 `碧蓝之海真人版 ()` | 命中《碧蓝之海》真人版电影 (2020) |

### 备用查询词：原名段补搜

文件名里通常同时带中文译名和原名（`长发公主.Tangled.2010.BluRay…`）。现在主查询词（中文段）结果不够确定时，自动拿年份之前的拉丁文段（`Tangled`）再搜一轮，两轮候选合并打分。

TMDB 搜「长发公主」不返回《魔发奇缘》——它的官方译名和「长发公主」字面上没有关系，中文查询词救不回来；`Tangled` 才是命中它的钥匙。主查询词一击命中时不打额外请求，正常文件的识别速度不变。

### 「真人版」后缀剥离

TMDB 标题不带媒介后缀。`碧蓝之海真人版` 搜不到任何东西，`碧蓝之海` 才是 2020 真人版电影在 TMDB 上的名字。`真人版 / 动画版 / 剧场版 / Live Action` 这类尾巴在主查询无结果时自动剥掉重搜。

### 修复：Season 目录被当成剧名

整理过的库是 `剧名 (年)/Season 01/…` 结构。对这类文件重新点「联网识别」时，`Season 01` 层会被当成片名搜出去（拿「Season」搜出过《寻爱交配季》），整部剧全部错配。现在 Season / Specials 层按容器名跳过，回溯到剧名目录取查询词。

### 修复：空年份不再留空括号

元数据缺年份时，目录名会渲染成 `碧蓝之海真人版 ()`。现在空字段留下的空括号直接去掉，得 `碧蓝之海真人版`；文件名模板同理。

## 升级

覆盖解压 `MediaShelf.exe` 即可，配置与缓存不动。已整理过的库如需按新逻辑重刷，重新「扫描 → 联网识别 → 预览并执行」即可，已命名正确的文件不会被动到。
