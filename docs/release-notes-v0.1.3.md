## MediaShelf v0.1.3

这一版修识别准确率、扫描体感和执行计划的核对方式。

### 识别

- **修复片名被截断**：`名侦探柯南VS怪盗基德` 里的 `VS` 会让解析在字母处断开，查询词只剩「名侦探柯南」，自然对不上。现在按分隔符切段取整段，`F1：狂飙飞车` 这类以字母开头的片名也不再丢前缀。
- **副标题前缀不再判死**：库里叫《冲出地球》、TMDB 叫《星游记之冲出地球》，字符相似度只有 0.67，原来直接算「无匹配」。现在一方完整包含另一方且长度差 ≥2 时给高分。
- **续集不误判**：`流浪地球` 和 `流浪地球2` 只差一个尾号，单独降权，不会靠年份蒙混过关。
- 全库 53 部实测：**53 部全部匹配，0 部需人工确认**（上一版是 51 部）。

### 扫描

- **先出行，后填参**：点扫描后文件列表立刻铺满表格（状态显示「探测中…」），参数由 4 路并发探测陆续回填。不用再盯着空表格等两分钟。
- 并发探测与静默子进程延续 0.1.2：NAS 上 10 个样本从 12.8 秒降到 1.0 秒。

### 界面

- **凭据可用状态直接显示**：右下角显示「数据源: TMDB（已连接）」绿色，或者「TMDB（不可用：原因）」红色，启动时和改完设置都会后台验证一次，不卡界面。
- **执行计划按文件合并**：原来 227 条操作摊成 227 行，现在每部片一行，标题栏统计「44 个文件 · 改名 44 · 写 nfo 51 · 海报 51」，一眼能核对该改的改了、该写 nfo 的写了。
- **计划预览加搜索**：顶部搜索框按片名、路径、备注过滤，几百部片的库也能定位到具体某部。
- 中文名、英文名、新文件名三列平分宽度，窄窗口下「新文件名」不再被挤成一条缝。

### 隐私提醒

API 凭据只存在本机 `%APPDATA%\MediaShelf\config.json`，不会写进日志、不随日志导出。
