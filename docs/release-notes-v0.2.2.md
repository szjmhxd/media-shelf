# MediaShelf v0.2.2

电视剧库（1053 个文件）批处理实测暴露的匹配问题修复。本版前：已匹配 622 / 需人工确认 260 / 无匹配 171；本版后：已匹配 1052 / 待人工 1。

## 修复

1. **EP 集号解析缺失，整目录被误判成电影**（最严重）
   `老九门.EP04.2016.HD1080P…` 这类 `EP04` 格式解析不出集号，同目录 48 个文件
   因「凑不齐两个不同集号」全部被判成电影，其中 6 集被错配到法国纪录片条目
   （文件名里同样带 `EP01` 的《Front Russe》系列）——直接执行会把剧集改成外国
   纪录片名。新增 `EP04` / `EP 04` / `Ep.04` 集号模式后，全目录正确判为剧集并
   匹配到《老九门》(2016)。

2. **剧集季播出年 ≠ 条目首播年导致大面积「需人工确认」**
   TMDB 剧集条目的年份是首播年（《家有儿女》2005、《爱情公寓》2009），而季目录
   标注的是该季播出年（S03 是 2007、S05 是 2020）。旧逻辑拿目录年份卡条目年份，
   一不符就降级，260 个正确匹配全部被拦。现在剧集不做年份降级（同名剧风险由
   相似度阈值兜底），电影的年份降级保持不变。

3. **TV 搜索不再用年份硬过滤**
   `first_air_date_year` 会把正主直接滤掉：搜《爱情公寓》+2014 只返回《球爱酒吧》
   (2014)，正主 2009 首播被过滤，整季 24 集无匹配。现在 TV 搜索裸搜，年份只在
   打分排序里参与。

4. **发行前缀与修复尾巴污染查询词**
   `W 国剧 武林外传 (2006) 2K 修复【…】` 解析出「W 国剧 武林外传」搜不到正主。
   现在剥掉 `W 国剧`/`国剧` 前缀，`2K 修复`/`蓝光修复` 等尾巴并入噪音清理。
   武林外传 81 集全部命中。

## 说明

- 目录错别字（如「云项天宫」应为「云顶天宫」）TMDB 仍然搜不到，走手动匹配或
  批处理的 override 映射，程序不做错别字猜测。
- 63 项测试。
