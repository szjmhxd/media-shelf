# MediaShelf v0.2.0

## 动漫剧集可以整理了

这一版从「电影工具」扩成了「影视库工具」。`N:\动漫` 这种电影、剧集、动画混在一起的库现在能一次整理完，不用再手工分拣。

实测一个 333 文件的真实动漫库：**329 部/集自动匹配，3 部需人工确认，1 部 TMDB 无数据**（碧蓝之海真人版）。其中剧集 145 集全部命中。

### 自动区分电影与剧集

规则只有一条，但很关键：**同一个目录里出现 ≥2 个不同集号才算剧集**。

单个文件就算名字里带「01」也可能是《101忠狗》这类片名。误判成剧集会把电影搬进 `Season 01`，收拾起来比重命名麻烦得多。

### 五种集号格式

实测一个库里 `SxxExx` 出现 **0 次**，反倒是这几种到处都是：

| 格式 | 例子 |
|---|---|
| 纯数字 | `01.flv` |
| 方括号 | `[DBD-Raws][Grand Blue][01][1080P].mkv` |
| 中文序号 | `第01话 那就是恋情的开端 4K.mp4` |
| 末尾数字 | `HUNTER×HUNTER(2011) 001.mkv` |
| 分隔符夹着 | `Dan Da Dan - 01 [IQIYI WebRip].mkv` |

季号从文件名或父目录找：`第二季 抢先版`（中文数字）、`胆大党S01`、`Season 02` 都认。

### 剧集目录结构

按 Jellyfin / Emby / Kodi 通用规范：

```
碧蓝之海 (2018)/
  tvshow.nfo          ← 整部剧只写一次
  poster.jpg
  Season 01/
    S01E01.nfo
    碧蓝之海.ぐらんぶる.S01E01.1080p.x265.10bit.mkv
```

集标题从 TMDB 的 season 接口取。实测《胆大党》第 1 集的集标题「那就是恋情的开端」与文件名完全一致。

### TMDB TV 接口

新增 `/search/tv`、`/tv/{id}`、`/tv/{id}/season/{n}` 三个接口，剧集走这套而不是电影接口。同一季的 season 数据有磁盘缓存，12 集只打一次请求。

## 命名按语言走

默认模板第二段从 `{en}` 换成 `{orig}`：

```
{cn}.{orig}.{year}.{source}.{res}.{codec}.{hdr}.{audio}-{group}
```

`{orig}` 按作品语言挑名字：

| 作品 | 输出 |
|---|---|
| 碧蓝之海（日本） | `碧蓝之海.ぐらんぶる.2018…` |
| 疯狂动物城（美国） | `疯狂动物城.Zootopia.2016…` |
| 寄生虫（韩国） | `寄生虫.기생충.2019…` |
| 流浪地球（中国） | `流浪地球.The.Wandering.Earth.2019…` |

判断依据是 TMDB 的 `original_language` 字段，不猜文本里有没有假名。中文作品的原名就是中文，会和第一段重复，此时退化成英文名。想要一律用英文，把第二段换回 `{en}` 就行。

## 修掉的匹配问题

- **英文剧名匹配不上**：TMDB 的 TV 接口里别名字段叫 `results`，电影才叫 `titles`，之前取英文名一直取不到。《Dan Da Dan》搜《胆大党》相似度是 0。
- **候选窗口把正确答案挤出去**：之前按标题相似度重排搜索结果再取前 2 个做详情。查询词是英文而 TMDB 返回中文名时，相关片的相似度是 0，会被自己的排序挤出窗口，最后匹配到一部无关片。现在候选窗口用 TMDB 的原始排序，相似度只用来在候选里挑最好的那个。
- **年份不匹配只降不罚**：《长发公主》(2010) 的标题相似度输《芭比之长发公主》(2002)，靠年份对不上才翻得回来。现在年份不符直接扣 0.2。

## 已知限制

- `碧蓝之海真人版` 这类 TMDB 没收录的作品搜不到，会标「无匹配」，走手动匹配。
- 同一部剧的不同字幕组版本（B 站版 / 喵萌奶茶屋）会各自生成文件名，靠分辨率字段区分。要合并成一个版本需要人工在预览里取消勾选多余的。
- 多集合并文件（一个 mkv 里 12 集）无法按单集拆分，会当普通文件处理。
